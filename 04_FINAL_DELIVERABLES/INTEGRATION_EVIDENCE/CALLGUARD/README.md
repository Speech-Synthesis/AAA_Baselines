## 3. Key Architectural Proofs

1. **Simulated Call Warning Visible:** The banner `⚠️ SIMULATED CALL — DEMO DATA ONLY` renders at the top of every page.
2. **Deterministic Phrase Challenge:** The voice verification component displays the fresh single-use phrase generated by AAA Engine and provides exact-match validation.
3. **Vishing Risk Panel Active:** The transcript scanner actively detects urgency cues and flags high-risk vishing attempts while safely allowing genuine security advisories (hard negatives).
4. **No Raw Audio Transit:** CallGuard does not capture or forward raw microphone data through the host application.
